# Unaccomplished Front Office

A one-file internal tool for the unaccomplished. shirt brand. Open `index.html` in a browser.

- **Machine**: spin formula, arena and reality into a new shirt, rendered live and judged against the 12 rules.
- **Rack**: every row of the Underwhelm Map as a printed shirt.
- **Map**: formula by reality grid with gaps marked.
- **Showdown**: head-to-head voting that turns friend taps into 1-5 scores for the sheet.

Shirt data is a snapshot of the Underwhelm Map sheet from Nov 17, 2026. Votes and filed ideas are stored in the browser only.
